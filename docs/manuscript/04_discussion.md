# Discussion

The course fixture verifies the distinction between sequence validation and
graph traversal. A path in the graph demonstrates connectivity, whereas
course validation requires the declared prerequisites to occur earlier in
the ordered lessons. The negative controls exercise these contracts using
the same local vocabulary.

The simulation verifies the shapes, normalization, and repeatability of
a finite teaching implementation. Its confidence and free-energy fields
are numerical diagnostics of this implementation. Extending the example
into a validated experimental model would require an independently defined
target, observations, and a justified comparison design. A software replay
does not measure course effectiveness, empirical decision quality, or
the validity of the free-energy principle. The conceptual sources provide
theoretical context for interpreting the example.

All inputs to the reported results are authored fixtures. The generator
records the complete course outcomes and simulator traces as JSON, which
can be regenerated with the source checkout's locked dependencies.
