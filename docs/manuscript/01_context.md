# Context and scope

The free-energy principle motivates accounts of perception and action in
terms of generative models and inference [@friston2010free]. Active Inference
provides a broader mathematical account of how preferences and information
can guide action [@parr2022active]. The repository uses these ideas as
educational material and supplies separate Python components that make
small examples inspectable.

A learner can read the authored foundational and domain material, encode
concepts as local JSON lessons, and use prerequisite declarations to check
an instructional sequence. A logical prerequisite in a course is a different
object from a relationship in the platform's general in-memory graph. The
examples here use the same concepts in both representations and check the
behavior of each API independently.
