# Abstract

The Active Inference Knowledge Environment combines educational material
with local tools for structured lessons, prerequisite graphs and finite
categorical simulations. This software note describes how the implemented
interfaces support a small, inspectable teaching workflow. A synthetic
course tests prerequisite ordering and local graph traversal. A seeded
simulation gives a reproducible belief trajectory and admits independent
checks of probability normalization. The examples establish specific
software behavior on supplied fixtures. The repository's wider learning
material and application designs provide context for future work.
