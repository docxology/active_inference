# Methods

The fixture creates lessons for prior beliefs, the observation model, and
posterior updates in a temporary local knowledge repository. The first
lesson precedes the second, which precedes the third. It loads an ordered
course and a reversed control from JSON. It searches for the posterior lesson
and evaluates both course orders with the repository's prerequisite validator.

The graph fixture adds the lessons as concept nodes with prerequisite edges.
The shortest-path method runs an unweighted traversal that considers edges
in both directions. A missing destination provides a separate negative control.

The teaching simulation registers a finite model with three hidden states,
four observations and two candidate actions. Eight steps use the simulation
engine's fixed random initialization. At each step, the engine draws an
observation from the current predictive distribution and conditions the
belief vector. It evaluates candidate actions using one-step transition
predictions and the source's preference and outcome-entropy terms. This is
the implemented greedy score; the transition predictions are used for
scoring while the loop retains the conditioned beliefs for the next sample.

The replay records observations, actions, posterior vectors and both reported
diagnostics. It repeats the identical configuration and checks the resulting
arrays for exact equality within the same run. Each posterior vector is also
checked for normalization. The JSON receipt and figure are generated by
`scripts/generate_manuscript_evidence.py`.
