# Manuscript sources

The numbered Markdown files describe the repository's implemented local
knowledge, course, graph and simulation workflows. `config.yaml` sets the
paper metadata and formats. `preamble.md` supplies the LaTeX additions and
`references.bib` supplies the cited works.

Run the [pinned render workflow](../manuscript-build.md). It generates
`output/data/teaching_fixture.json` and the figure referenced by the paper.
